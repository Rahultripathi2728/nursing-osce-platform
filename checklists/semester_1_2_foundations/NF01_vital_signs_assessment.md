### Step-by-Step Scoring Rubric:

| Step # | Evaluation Step | Max | Score [0 / 1 / 2] | Examiner Rationale & Critical Points |
| :---: | :--- | :---: | :---: | :--- |
| **Part A: Preparation & Patient Readiness** | | | | |
| 1 | Verified identity of patient; explained purpose of measuring TPR & BP; ensured patient rested for 5 minutes without talking/caffeine. | 2 | | Physiological resting baseline. |
| 2 | Performed WHO hand hygiene; cleaned diaphragm of stethoscope and thermometer probe with 70% alcohol swab. | 1 | | Prevents cross-transmission. |
| **Part B: Temperature Assessment** | | | | |
| 3 | Assessed axilla (dried with tissue if sweaty without rubbing); placed thermometer probe in center of axilla; brought patient's arm snugly across chest. | 2 | | Ensures intimate skin contact with probe. |
| 4 | Kept in place until audible beep; read temperature at eye level; cleaned thermometer from stem to bulb. | 1 | | Stem to bulb principle (clean to dirty). |
| **Part C: Pulse & Respiration Assessment** | | | | |
| 5 | Located radial pulse using pads of first three fingers along groove of radial styloid process; applied gentle pressure without obliterating pulse. | 2 | | Using thumb is prohibited (examiner's own arterial pulse interferes). |
| 6 | Counted radial pulse for 60 seconds (noted rate, rhythm, and volume/fullness). | 2 | | 60-second count required for clinical accuracy. |
| 7 | Maintained hand in position on wrist while subtly counting respirations (inspected chest rise & fall for 60 full seconds). | 2 | | Prevents patient from voluntarily altering breathing pattern. |
| **Part D: Blood Pressure Measurement (Auscultatory)** | | | | |
| 8 | Supported patient's arm at heart level, palm up; placed appropriate cuff 2.5 cm (1 inch) above antecubital fossa with artery mark centered over brachial artery. | 2 | | Cuff bladder width must cover 40% arm circumference. |
| 9 | Performed palpatory estimation of systolic pressure: inflated cuff while palpating radial pulse until pulse vanished; noted reading and deflated completely. | 2 | | Prevents underestimating BP due to auscultatory gap. |
| 10 | Placed diaphragm lightly over brachial artery; reinflated cuff 30 mmHg above palpatory systolic; deflated at 2-3 mmHg/sec. | 2 | | Accurate deflation rate ensures clear Korotkoff sound identification. |
| 11 | Accurately identified Phase I Korotkoff (Systolic) and Phase V (Diastolic); deflated cuff rapidly to zero. | 1 | | Standard diagnostic criteria. |
| **Part E: Documentation & Communication** | | | | |
| 12 | Disposed used swabs, repositioned patient comfortably, communicated vital sign values reassuringly, and recorded T, P, R, BP in TPR chart. | 1 | | Complete clinical record. |
